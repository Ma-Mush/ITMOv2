# GEMINI.md — Правила разработки Lizard Arena

Данный файл содержит обязательные правила, ограничения и стандарты для любого ИИ-агента и разработчика, работающего в этом репозитории.

---

## 1. Незыблемые Игровые Правила (Core Game Rules)

1. **Здоровье и Очки едины**:
   * Базовое стартовое здоровье ящерицы — **ровно 100 очков (HP)**.
   * При достижении $\text{HP} \le 0$ ящерица считается погибшей и распадается на кластер ягод.
2. **Сбор ягод**:
   * Каждая ягодка моментально добавляет **+10 очков / HP**.
   * Общее количество ягод на карте поддерживается сервером на уровне **600 шт.**
3. **Формула визуального роста**:
   * Масштаб ящерицы строго следует формуле:
     $$S = \sqrt{\frac{\max(10, \text{Score})}{100}}$$
   * Радиус головы, толщина сегментов и длина тела масштабируются пропорционально $S$.
4. **Боевая механика (Урон)**:
   * Нанесение урона происходит при касании головы атакующего к телу/голове жертвы:
     $$D = 25 + 10 \cdot (S - 1)$$
   * Нападающая ящерица восстанавливает **+40%** от нанесённого урона в виде здоровья.
   * Обязателен кулдаун укуса (`BITE_COOLDOWN_MS = 350ms`) на одну и ту же цель для предотвращения мгновенной гибели за 1 кадр.
5. **Боты**:
   * В мире всегда поддерживается популяция минимум из **14 ИИ-ботов**.

---

## 2. Архитектурные Ограничения и Кодстайл

1. **Авторитетный Сервер (Server Authority)**:
   * Физика, коллизии, урон, сбор ягод и здоровье рассчитываются **исключительно на сервере** (`server/GameRoom.ts`).
   * Клиент отправляет только свой ввод (`targetAngle`, `isBoosting`) и отображает снапшоты мира.
2. **Нулевые внешние медиа-зависимости (Zero External Assets)**:
   * **Графика**: Только процедурная отрисовка на HTML5 Canvas 2D (кинематика лап, язык, чешуя, ягоды). Никаких внешних спрайтов или картинок.
   * **Звуки**: Только процедурный синтез через Web Audio API (`SoundEffects.ts`). Запрещено подключать внешние `.mp3` или `.wav` ссылки, которые могут стать битыми (404) или создавать задержки загрузки.
3. **Производительность и Сложность $O(1)$**:
   * Запрещены двойные вложенные циклы $O(N^2)$ проверки коллизий ягод.
   * Все пространственные запросы (поиск ягод вокруг ящерицы) должны проходить через `SpatialGrid` (хэш-сетка 150px).
4. **Типизация (TypeScript)**:
   * Все сетевые структуры и параметры сущностей объявляются в папке `shared/` (`types.ts`, `constants.ts`, `math.ts`).
   * Запрещено использование `any` без явной необходимости. Режим TypeScript — `strict: true`.

---

## 3. Регламент Тестирования

* Любые изменения в коде должны валидироваться:
  1. `npm run build` — проверка отсутствия ошибок компиляции TypeScript и сборки Vite.
  2. `npm run test:e2e` — автоматический Playwright-тест полного сценария (подключение, спавн, движение мыши, проверка отображения HP и скриншоты).
