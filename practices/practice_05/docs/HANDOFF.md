## 1. Текущее состояние реализации

В проекте полностью реализованы и интегрированы обе запланированные фичи:

* **Фича A (Базовая арена и кинематика):**
  * Поле $3600 \times 3600$ с поддержкой плотности 600 сочных ягод.
  * Процедурная ящерица с цепной кинематикой позвоночника Verlet (14–42 звена).
  * Диагональная походка 4 лап с когтями, анимированные глаза, раздвоенный язык.
  * Формула масштабирования: $S = \sqrt{\frac{\max(10, \text{score})}{100}}$.
  * Сбор ягод (+10 HP), динамический зум камеры при росте.

* **Фича B (Боевая механика и боты):**
  * Авторитетный расчёт урона на сервере: $D = 25 + 10 \cdot (S - 1)$.
  * Кулдаун укуса 350 мс для исключения мгновенной гибели за один кадр.
  * Механика вампиризма (+40% от нанесённого урона возвращается атакующему).
  * Популяция из 14 ИИ-ботов с FSM (`FORAGE` $\rightarrow$ `ATTACK` $\rightarrow$ `FLEE`).
  * Дроп кластера ягод при гибели ящерицы.

## 3. Проверки и воспроизводимость

Все тесты и сборки запускаются через единый доверенный раннер:
```bash
# Быстрая проверка типизации, сборки, формул skill и тулов MCP:
sh scripts/check.sh

# Комплексный pre-commit с Playwright E2E тестом в браузере:
npm run pre-commit
```

Все проверки завершаются с кодом `0` (0 ошибок TypeScript, чистый бандл Vite, 100% прохождение E2E-сценария).

---

## 4. Архитектурные ограничения

1. **Zero External Assets:** никаких внешних спрайтов или `.mp3` ссылок. Звук процедурный (`SoundEffects.ts`), графика векторная Canvas 2D.
2. **Сложность $O(1)$:** все коллизии и поиск целей ботами строго через `SpatialGrid`.
3. **Server Authority:** весь урон и физика считаются исключительно на Node.js WebSocket-сервере.
