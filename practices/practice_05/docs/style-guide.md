# Style Guide & Архитектурные правила Lizard Arena

> Обязательные стандарты кода и процедур разработки.

---

## 1. Архитектурные инварианты
1. **Проверяй поведение через публичный интерфейс:**
   - Для сервера — через контракт WebSocket-сообщений (`shared/types.ts`) и чистые функции (`shared/math.ts`).
   - Для клиента — через браузерный E2E-тест Playwright (`scripts/test_gameplay.mjs`).
2. **Используй типы и соглашения проекта:**
   - Строгая типизация TypeScript (`strict: true`). Никаких нетипизированных `any` без крайней необходимости.
   - Все сущности и пакеты определены в папке `shared/`.
3. **Не добавляй framework ради маленькой правки:**
   - Графика: чистый HTML5 Canvas 2D векторный рендеринг без сторонних движков.
   - Звук: процедурный синтез Web Audio API (`SoundEffects.ts`), запрещено подключать внешние `.mp3` ссылки.
4. **Не ослабляй runner ради зелёного результата:**
   - Проверки в `scripts/check.sh` и `scripts/pre-commit.sh` должны оставаться строгими (`set -e`).
5. **Сложность $O(1)$ для пространственных запросов:**
   - Все проверки коллизий ягод и ящериц должны производиться через `SpatialGrid`.

---

## 2. Пример чистого применения
Функции расчёта урона и масштабирования ящерицы изолированы в чистых функциях `shared/math.ts`:
```typescript
export function getScaleFromScore(score: number): number {
  return Math.sqrt(Math.max(10, score) / BASE_SCORE);
}
```
Они покрыты тестами в `scripts/test_balance.ts` и в MCP-сервере `server/mcp/arena-mcp-server.ts`.
